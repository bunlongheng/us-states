## Security Policy

US States is a client-side static game with no backend, auth, or user data, so the attack surface is minimal.

## Reporting a vulnerability

If you find a security issue, please report it privately rather than opening a public issue:

- Open a private security advisory via GitHub (Security tab -> Report a vulnerability), or
- Email bheng.code@gmail.com

Dependency advisories are watched via `npm audit` in CI.
